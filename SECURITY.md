# Security Policy

## Supported Scope

This repository mainly contains skill definition documents and templates.

Security concerns typically include:

- Malicious or unsafe prompt instructions
- Data-leak risks in examples or templates
- Unsafe default guidance that may trigger destructive commands

## Reporting a Vulnerability

Please report security issues privately before opening public disclosure.

Recommended process:

1. Open a private communication channel with maintainers (if available).
2. If private channel is unavailable, open a minimal issue without exploit details and mark title with `[security]`.
3. Include affected file paths, impact, and reproduction steps.

## Response Targets

- Initial triage: within 7 days
- Remediation plan: within 14 days after confirmation
