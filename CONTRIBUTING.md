# Contributing Guide

Thanks for contributing to `program-gozero`.

## Scope

This repository hosts reusable AI skills for go-zero related workflows.

## How To Contribute

1. Fork the repository and create your branch.
2. Keep changes focused and small.
3. Update docs when behavior or usage changes.
4. Open a Pull Request with clear context.

## Skill Contribution Checklist

- Keep naming concise and descriptive.
- Provide at least:
  - `SKILL.md`
  - `README.md`
- Prefer bilingual docs (`*.zh.md`) for wider adoption.
- Include invocation examples and clear boundaries.
- Avoid unrelated refactoring.

## Pull Request Expectations

- Describe motivation and expected outcome.
- Explain what was tested (or why tests are not applicable).
- Mention any compatibility or migration impact.

## Code Style

- Follow existing repo style and wording conventions.
- Prefer minimal and explicit changes.
- Keep markdown structure consistent.
